## What is this?

This is a repository created to host content and templates for the San Diego City College MESA program. Developed by Alexander Daumas.

## Why?

- It's a foolproof way to host documents online.
- It's simple and easy to use.
- It is very convenient because there are HTML files being used here.

## How to use the templates?

1. Go to Canvas.
2. Create a new page.
3. See the text editor. On the bottom right corner there is a symbol `</>` click it. You should see the text editor have numbered lines now.
4. Come to the Git-Hub Page and choose the template that you wish to use.
5. Copy to clip board.
6. Paste in the Canvas text editor.
7. Press the `</>` symbol again, you should see the template load properly.
8. Edit like Normal

A few tips.

- If you wish to change the text inside a button, highlighted first then paste over it whatever you wanted to appear in the button. If you want it to be a link or URL highlighted again and select the URL button on the text editor.
- To add images use the native image tool in the canvas editor.

## Recommendations

This system is using to the highest degree the HTML function inside Canvas therefore is not officially supported to work. For making future templates or modifying the HTML make sure to use inline CSS and run it though Premailer. It will basically render HTML as if it where an email.
